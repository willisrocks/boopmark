# Tags UI: Compact Filter Bar and `/tags` Library — Implementation Plan

**Spec:** `docs/superpowers/specs/2026-10-31-tag-management-design.md`, section "4. UI" and Rollout
step 2. Mockups: `assets/2026-10-31-tag-management/mockup-filter.png`, `mockup-library.png`.
**Branch:** `feat-tags-ui`
**Goal:** the filter bar fits in one row at any library size (top tags, "More tags" with an
alias-aware search popover, multi-select), and `/tags` lists canonical tags with counts and
aliases, with rename, manual merge, batch undo and a link to pending proposals.

## Auto-pilot decisions

## Steps

Each step ends with `cargo test -p boopmark-server` green and a commit.

1. **Pure library logic** — `domain/tag_library.rs`: `TagRow { name, count, aliases }` built from
   tag counts plus alias rows; `top_tags(rows, n, active)`; `search(rows, q, limit)`;
   `sort_rows(rows, sort)`; `filter_rows(rows, q)`. Unit tests for k8s→kubernetes, compact-key
   matches, ranking, ties, active tags excluded from top N.
2. **Filter bar** — `filters_inner.html`/`filters.html`/`filters_oob.html`: active chips with ×,
   top-N chips with counts, "More tags (N)" popover, sort select; URLs built server-side and
   URL-encoded. `GET /tags/search` handler and `tags/search_results.html` fragment. Delegated
   popover script.
3. **Library page** — `GET /tags` (`tags/library.html` + `tags/library_body.html`): summary line,
   proposals banner, filter box and sort (HTMX partial), table with Rename / Merge into…, bulk
   select bar, a shared `<dialog>` for rename and merge, batch history with Undo.
   `POST /tags/merge`, `POST /tags/batches/{id}/undo` return the body fragment with a flash.
4. **Header link** and Tailwind rebuild of `static/css/output.css`.
5. **E2E** — `tests/e2e/tags.spec.js`: seed through the form endpoint; at most 10 chips plus More;
   multi-select add and remove; merge `k8s` into `kubernetes` on `/tags`; popover search `k8s`
   finds `kubernetes` and Enter filters; rename; undo restores; mobile width keeps one row and no
   horizontal scroll.
6. **Evidence** — before/after screenshots on the 600-bookmark tag-lab seed for the PR.
